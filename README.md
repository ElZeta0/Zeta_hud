## 📦 Installation

**1.** Download the latest version of Zeta HUD.

**2.** Extract the files into your FiveM server's resources directory.

**3.** Rename the resource folder to:

```text
zeta_hud
```

**4.** Add this line to your `server.cfg`:

```cfg
ensure zeta_hud
```

**5.** Restart your FiveM server.

> **Important:** The resource must be named `zeta_hud` to work correctly.
